# Sources

The manuals, data sheets and libraries the host and the stick are built on, each at the version the code relies on.

- nrf_to_nrf by TMRh20, the radio library of both sketches: https://github.com/TMRh20/nrf_to_nrf at tag v1.7.0, commit d1810ab1d6fb9ef8cedf6487d54fcacf0337ee65 (https://github.com/TMRh20/nrf_to_nrf/tree/d1810ab1d6fb9ef8cedf6487d54fcacf0337ee65). CI installs it as `nrf_to_nrf@1.7.0` from the Arduino Library Manager, which builds its release 1.7.0 from that tag.
- TDK, "Piezoelectronic buzzers, Without oscillator circuit, Pin terminal type, PS series", catalog revision 20220222 (piezoelectronic_buzzer_ps_en, February 2022), the data sheet of the host's passive piezo buzzer, the TDK PS1240P02BT: https://cdn-shop.adafruit.com/product-files/160/160_ds.pdf, the copy Adafruit links from its product 160 (https://www.adafruit.com/product/160), 431437 bytes, SHA-256 1cc2789af2cb03705e09b8b6e49710c4003f4e5f6fbeb7f0873b8a25c686e60e, read on 2026-11-07. TDK's own copy of the catalog, https://product.tdk.com/system/files/dam/doc/product/sw_piezo/sw_piezo/piezo-buzzer/catalog/piezoelectronic_buzzer_ps_en.pdf, refused the read with HTTP 403 that day, so this line lists Adafruit's copy. The catalog doesn't grant a license to copy it, so this repository doesn't hold a copy.
